\# 🎨 Image Colorization Generative AI



An AI-powered web application that converts black-and-white images into color images using a pretrained deep learning colorization model.



\## 🚀 Features



\- Upload a black-and-white image

\- AI-based automatic image colorization

\- Supports JPG, JPEG, and PNG images

\- Displays the original and colorized images

\- Download the generated colorized image

\- Automatically saves generated images with sequential filenames



\## 🛠️ Technologies Used



\- Python

\- OpenCV

\- NumPy

\- Streamlit

\- Deep Learning

\- Caffe Colorization Model
